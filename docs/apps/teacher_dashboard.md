# 👨‍🏫 Документація Застосунка «Кабінет Викладача та Аналітика» (`apps/teacher`)

Цей документ визначає повну технічну та педагогічну архітектуру веб-застосунка **«Кабінет Викладача та Аналітика» (`apps/teacher`)**, що функціонує на порту `3003` у складі платформи **Smart-BKT-Chain**.

---

## 🎯 1. Призначення та Педагогічна Роль

Застосунок `apps/teacher` є **центром педагогічного нагляду, діагностики та верифікації знань**, який забезпечує:
1. **Когортний моніторинг успішності:** візуалізація розподілу учнів за рівнями майстерності (Mastery $\ge 0.85$, Proficient, Basic, At Risk).
2. **Детекцію аномалій академічної доброчесності:** аналіз збігів часової телеметрії (WPM > 120, надшвидкі розв'язки < 3 сек, масивні вставки тексту без редагування).
3. **Чергу ручної перевірки завдань (Review Queue):** розширений інспектор `ReviewQueueInspector` для перевірки есе, проєктних задач та спірних рішень з можливістю затвердження (`APPROVE`) або відхилення (`REJECT`) із коментарем.
4. **Інтерактивну навігацію графом курсу:** інспектор графу компетенцій `CourseGraphViewer` для перегляду зв'язків між навичками, пререквізитів та банку завдань кожного модуля.

---

## 🏛️ 2. Архітектура Інтерфейсу (UI Shell Standard)

- **Шапка (`h-14`):** вибір навчального курсу, пошуковий рядок учнів, лічильник черги перевірки, індикатор захищеності з'єднання.
- **Вертикальний рейл (`w-14`):** швидкі вкладки (`analytics` — когортна аналітика, `reviews` — черга ручної перевірки, `graph` — граф курсу, `audit` — блокчейн-аудит, `study` — перехід до підручника).
- **Бічна панель (`w-[380px]`):** структурована на базі безрамкових секцій `<DrawerSection>` (Правило 7):
  - *Секція 1: Фільтри когорти (All, Proficient, At-Risk, Anomalies)*
  - *Секція 2: Реєстр учнів класу із пошуком у реальному часі*
  - *Секція 3: Швидкі метрики когорти (середній BKT, середня швидкість, інциденти)*
- **Центральне полотно:**
  - `ReviewQueueInspector`: детальний розбір відповідей учнів, історія спроб, критерії оцінювання (рубрики) та еталонна відповідь.
  - `CourseGraphViewer`: деревоподібна візуалізація вузлів навичок та завдань.
  - `AnomalyTreeWidget`: виявлення патернів нечесної поведінки або перевтоми.

## 🛠️ 3. Технічний Стек та Запуск
- **Стек:** Next.js 16 (Webpack mode), React 19, Socket.io-client, Lucide React, Tailwind CSS v4, `@sbc/types`, `@sbc/ui`.
- **Запуск у режимі розробки:**
  ```bash
  npm run dev:teacher
  ```
  *(Доступно за адресою: [http://localhost:3003](http://localhost:3003))*.
- **Production-збірка:**
  ```bash
  npm run build:teacher
  ```
