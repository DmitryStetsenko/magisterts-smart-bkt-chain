# 👨‍🏫 Документація Застосунка «Кабінет Викладача та Аналітика» (`apps/teacher`)

Цей документ визначає повну технічну та педагогічну архітектуру веб-застосунка **«Кабінет Викладача та Аналітика» (`apps/teacher`)**, що функціонує на порту `3003` у складі платформи **Smart-BKT-Chain**.

---

## 🎯 1. Призначення та Педагогічна Роль

Застосунок `apps/teacher` є **центром педагогічного нагляду, діагностики та верифікації знань**, який забезпечує:
1. **Когортний моніторинг успішності:** візуалізація розподілу учнів за рівнями майстерності (Mastery $\ge 0.85$, Proficient, Basic, At Risk).
2. **Детекцію аномалій академічної доброчесності:** аналіз збігів часової телеметрії (WPM > 120, надшвидкі розв'язки < 3 сек, масивні вставки тексту без редагування).
3. **Чергу ручної перевірки завдань (Review Queue):** розширений інспектор `ReviewQueueInspector` для перевірки есе, проєктних задач та спірних рішень з можливістю затвердження (`APPROVE`) або відхилення (`REJECT`) із коментарем.
4. **Інтерактивну навігацію графом курсу:** інспектор графу компетенцій `CourseGraphViewer` для перегляду зв'язків між навичками, пререквізитів та банку завдань кожного модуля.

---

## 🏛️ 2. Архітектура Інтерфейсу (Minimalist Borderless UI — AppShellLayout v2.0)

Інтерфейс застосунка реалізовано на базі канонічного компонента **`AppShellLayout`** (`@sbc/ui`) за принципом **Minimalist Borderless Design** (без вкладених рамок-«матрьошок» та зайвих контейнерів) із суворою ізоляцією скролінгу:
- **Кореневий контейнер (`h-screen w-screen overflow-hidden`):** вікно жорстко зафіксоване, браузерний глобальний скрол заблоковано.
- **Дворівнева шапка (`h-[56px]` — Minimalist Two-Tier Header):**
  - *Поверх 1 (Бренд та Навчальний предмет):* безрамкова іконка `ShieldCheck` (`w-7 h-7 rounded-lg`), назва системи `Smart-BKT-Chain`, моноширинний підпис `Teacher`, вертикальний розділювач `bg-slate-800` та назва активного курсу (`courseBadge`).
  - *Поверх 2 (Хлібні крихти `Breadcrumbs`):* виводяться виключно в хедері (`mt-1.5`) із розділювачем `/` та текстовими бейджами у дужках `({badge})` без рамок.
  - *Права зона:* плоский пошуковий селектор студента (`bg-slate-800/50 rounded-lg`) з індикатором $P(L)$ та безрамкова кнопка профілю викладача, що відкриває уніфікований **`UserProfileDrawer`** (де здійснюється перемикання активного курсу та огляд статусу когорти).
- **Вертикальна рейка Minimalist Borderless Icon Rail (`w-12`):** швидке перемикання робочих табів (`w-9 h-9 rounded-lg`) без важких рамок і тіней:
  - `analytics` (BarChart3): огляд групи та радар ризиків;
  - `coursemap` (Network): граф навичок та завдання;
  - `reviews` (ClipboardCheck): черга перевірки відповідей (Human-in-the-Loop) з інтерактивним числовим бейджем кількості робіт (`reviewQueue.length`);
  - `metrics-audit` (FlaskConical): математичний аудит та пісочниця симулятора BKT (What-If Sandbox);
  - *Нижній стек екосистеми:* автоматичні безрамкові посилання через `@sbc/routes` на Підручник (`apps/study`), Студентський кабінет (`apps/student`), Адмінку (`apps/admin`), Документацію (`apps/docs`) та параметри оцінювання (`settings`).
- **Висувний Drawer (`sm:w-[300px] lg:w-[320px]`):** структурований на базі безрамкових секцій `<DrawerSection>` (Правило 7) з текстовими лічильниками `({badge})` та розділювачами списків `divide-y divide-slate-800/50`:
  - *Секція 1: Розподіл майстерності когорти та радар ризиків*
  - *Секція 2: Реєстр учнів класу із плоскими безрамковими рядками*
  - *Секція 3: Аудит тріад Блума, когнітивні пастки та черга перевірки*
- **Центральне полотно (`<main className="flex-1 overflow-y-auto">` — Clean Borderless Canvas):**
  - Плоский однорядковий верхній тулбар (`border-b border-slate-800/80`) замість багатоповерхових карток та банерів.
  - `ReviewQueueInspector`: двоколонковий розбір відповідей учнів, історія спроб, критерії оцінювання та еталонна відповідь без зовнішньої коробки.
  - `CourseGraphViewer`: чиста безрамкова ієрархія модулів та когнітивних тріад (`divide-y divide-slate-800/80`).
  - `MetricsAuditInspector`: верифікація формул BKT та реєстр адаптивних механізмів.

## 🛠️ 3. Технічний Стек та Запуск
- **Стек:** Next.js 16 (Webpack mode), React 19, Socket.io-client, Lucide React, Tailwind CSS v4, `@sbc/types`, `@sbc/ui`.
- **Запуск у режимі розробки:**
  ```bash
  npm run dev:teacher
  ```
  *(Доступно за адресою: [http://localhost:3003](http://localhost:3003))*.
- **Production-збірка:**
  ```bash
  npm run build:teacher
  ```
