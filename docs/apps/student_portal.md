# 💻 Документація Застосунка «Студентський Кабінет та Тренажер» (`apps/student`)

Цей документ визначає повну технічну, дидактичну та інженерну архітектуру веб-застосунка **«Студентський Кабінет та Тренажер» (`apps/student`)**, що функціонує на порту `3002` у складі платформи **Smart-BKT-Chain**.

---

## 🎯 1. Призначення та Педагогічна Роль

Застосунок `apps/student` є **головним практичним полігоном учня**, призначеним для:
1. **Формативного та діагностичного оцінювання знань:** вирішення завдань з написання коду (`CODE`), концептуальних тестів (`SINGLE_CHOICE`, `MULTIPLE_CHOICE`) та аналітичних есе (`TEXT_ESSAY`).
2. **Адаптивного навчання на базі моделі BKT:** безперервний перерахунок апостеріорної ймовірності засвоєння навички $P(L_n)$ за формулами Bayesian Knowledge Tracing.
3. **Збору поведінкової телеметрії:** фіксація темпу набору (WPM), інтервалів пауз, подій видалення та вставок (copy-paste) для формування коефіцієнта академічної доброчесності.
4. **Інтерактивного Сократівського риштування (Scaffolding):** надання багаторівневих евристичних підказок при виникненні когнітивних труднощів.

---

## 🏛️ 2. Архітектура Інтерфейсу (UI Shell Standard — AppShellLayout v2.0)

Інтерфейс застосунка реалізовано на базі канонічного компонента **`AppShellLayout`** (`@sbc/ui`) із суворою ізоляцією скролінгу:
- **Кореневий контейнер (`h-screen w-screen overflow-hidden`):** вікно жорстко зафіксоване, браузерний глобальний скрол заблоковано.
- **Шапка (`h-14`):** брендинг `Smart-BKT-Chain` із бейджем `Student Portal v2.0`, центральний індикатор загального прогресу курсу ($P(L)$), бейдж поточної навички, селектор курсів та профіль користувача.
- **Вертикальна рейка Opera Rail (`w-14`):** швидке перемикання робочих табів:
  - `task` (BookOpen): активний редактор завдань та умова;
  - `bkt` (Sparkles): інтерактивний граф навичок DAG;
  - `tree` (Network): гейміфіковане дерево компетенцій (Knowledge Tree);
  - *Нижній стек екосистеми:* автоматичні швидкі посилання через `@sbc/routes` на Підручник (`apps/study`), Кабінет Викладача (`apps/teacher`), Адмінку (`apps/admin`), Документацію (`apps/docs`) та системні налаштування.
- **Висувний Drawer (`w-[380px]`):** структурований на базі безрамкових секцій `<DrawerSection>` (Правило 7) з незалежним скролом:
  - *Секція 1: Прогрес навички BKT ($P(L_n)$)*
  - *Секція 2: Умова та контекст завдання (перемикач «Умова» / «Історія спроб»)*
  - *Секція 3: Рекомендація адаптивного секвенсора*
  - *Секція 4: Відкриті тест-кейси та валідація*
  - *Секція 5: Багаторівневі Сократівські підказки*
  - *Секція 6: Деталізація вердиктів викладача та коментарі*
- **Центральна робоча зона (`<main className="flex-1 overflow-hidden">`):**
  - `MonacoCodeEditor`: редактор коду з підсвіткою синтаксису, номерами рядків та гарячими клавішами.
  - `QuizTaskEditor`: рандомізовані варіанти відповідей з вимірюванням латентності реакції.
  - `EssayTaskEditor`: текстовий аналізатор розгорнутих відповідей.
  - `GameSkillTreeWidget`: розгортання дерева навичок на весь екран при закритому сайдбарі.

## 📊 3. Математика BKT та Адаптивний Секвенсор

При кожному поданні рішення (`SubmissionDto`) ядро бекенду розраховує:
1. **Апостеріорне оновлення знання:**
   - Якщо спроба успішна ($O_t = 1$):
     $$P(L_t | O_t=1) = \frac{P(L_{t-1}) \cdot (1 - P(S))}{P(L_{t-1}) \cdot (1 - P(S)) + (1 - P(L_{t-1})) \cdot P(G)}$$
   - Якщо спроба хибна ($O_t = 0$):
     $$P(L_t | O_t=0) = \frac{P(L_{t-1}) \cdot P(S)}{P(L_{t-1}) \cdot P(S) + (1 - P(L_{t-1})) \cdot (1 - P(G))}$$
2. **Перехід між кроками:**
   $$P(L_t) = P(L_t | O_t) + (1 - P(L_t | O_t)) \cdot P(T)$$
3. **Адаптивні рішення:**
   - При $P(L_n) \ge 0.85$ навичка вважається засвоєною (`ADVANCE`).
   - При невдачах на базових задачах активується режим ремедіації (`REMEDIATE`) або рекомендація теоретичного опрацювання (`THEORY_REVIEW`) з переходом у `apps/study`.

## 🛠️ 4. Технічний Стек та Запуск
- **Стек:** Next.js 16 (Webpack mode), React 19, Monaco Editor (`@monaco-editor/react`), Socket.io-client, Tailwind CSS v4, `@sbc/types`, `@sbc/ui`.
- **Запуск у режимі розробки:**
  ```bash
  npm run dev:student
  ```
  *(Доступно за адресою: [http://localhost:3002](http://localhost:3002))*.
- **Production-збірка:**
  ```bash
  npm run build:student
  ```
