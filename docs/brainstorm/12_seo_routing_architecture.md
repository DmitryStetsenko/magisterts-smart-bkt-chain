# 🌐 Архітектурний Стандарт Семантичної Маршрутизації та SEO (Semantic Routing & Deep Linking Standard)

Цей документ фіксує результати фундаментального мозкового штурму щодо подолання проблеми односторінкових застосунків (SPA Anti-Pattern) у монорепозиторії **Smart-BKT-Chain** та впровадження повноцінного, SEO-оптимізованого та людино-зрозумілого роутингу на базі Next.js App Router.

---

## 🎯 1. Проблематика та Архітектурний Виклик

### 1.1 Поточний стан (SPA Anti-Pattern)
До цього часу застосунки екосистеми (`apps/study`, `apps/student`) функціонували в межах єдиного кореневого маршруту `/`, а перемикання курсів, модулів та уроків здійснювалося через локальний стан React `useState()` або `localStorage`.

### 1.2 Негативні наслідки для платформи:
1. **Нульова індексація (Zero SEO):** Пошукові роботи (Google, Bing) індексують лише корінь сайту. Усі навчальні матеріали, дидактичні статті, розбори оман та пісочниці коду залишаються невидимими для пошукових систем.
2. **Втрата контексту (Broken History & Deep Linking):** Оновлення сторінки (F5) або використання кнопок браузера «Назад» / «Вперед» скидає стан до дефолтного курсу (`js-dev`), замість утримання активного навчального юніту.
3. **Розрив міжпортальної взаємодії:** Перехід із підручника (`apps/study`) до тренажера (`apps/student`) через посилання на кшталт `?skill=school-alg-basics` ігнорувався тренажером, змушуючи учня повторно шукати відповідний курс та тему.
4. **Неможливість академічного цитування:** Вчителі та учні не мали змоги поділитися прямим посиланням на конкретний параграф теорії або завдання.

## 🏛️ 2. Концепція Єдиної Онтологічної Ієрархії Маршрутів

Кожен навчальний елемент платформи однозначно ідентифікується канонічним шляхом:

$$\text{Canonical URL} = \text{Domain} / \text{Scope} / [\text{courseSlug}] / [\text{moduleSlug}] / [\text{unitSlug}]$$

### 2.1 Матриця роутів екосистеми Smart-BKT-Chain

| Застосунок | Порт | Область (Scope) | Канонічний патерн | Приклад повного URL |
| :--- | :---: | :--- | :--- | :--- |
| **`apps/study`** (Підручник) | `3006` | `/courses` | `/courses/[courseSlug]/[moduleSlug]/[unitSlug]` | `/courses/web-algorithms-school/school-alg-basics/variables-and-types` |
| **`apps/student`** (Тренажер) | `3002` | `/practice` | `/practice/[courseSlug]/[skillSlug]` | `/practice/web-algorithms-school/school-alg-basics` |
| **`apps/teacher`** (Викладач) | `3003` | `/curriculum` | `/curriculum/[courseSlug]/[skillSlug]` | `/curriculum/web-algorithms-school/school-alg-basics` |
| **`apps/admin`** (CMS DAG) | `3004` | `/graph` | `/graph/[courseSlug]/[skillSlug]` | `/graph/web-algorithms-school/school-alg-basics` |

## 🔍 3. Стандарти SEO-Оптимізації для Навчального простору (`apps/study`)

### 3.1 Динамічні метадані (Dynamic Metadata API)
Кожна сторінка уроку в обов'язковому порядку експортує функцію `generateMetadata`:
- **`<title>`**: `{Назва уроку} | {Назва курсу} (10–11 класи)`;
- **`<meta name="description">`**: Коротке резюме навчального уроку (`summary`);
- **`canonical`**: Абсолютне посилання на офіційний канонічний шлях;
- **OpenGraph / Twitter Cards**: Формування карток для соціальних мереж та месенджерів (Telegram, Discord, Google Classroom).

### 3.2 Семантична мікророзмітка Schema.org (JSON-LD)
У тіло сторінки вбудовуються структуровані дані:
- `EducationalOccupationalCredential` / `Course`: Опис курсу, дисципліни, цільової аудиторії (10–11 класи).
- `LearningResource`: Визначення типу матеріалу (теоретичний посібник, пісочниця коду, розбір оман).
- `BreadcrumbList`: Формування структурованого ланцюжка навігації для пошукової видачі Google.

### 3.3 Статична генерація сторінок (Static Site Generation — SSG)
- Використання функції `generateStaticParams()` дозволяє згенерувати 100% сторінок навчальної програми на етапі білду (`next build`).
- Забезпечує миттєву швидкість відповіді сервера (TTFB < 50 мс) та 100 балів у Google Lighthouse.

## 🔄 4. Специфікація Міжпортальних Глибоких Посилань (Cross-App Deep Linking Protocol)

### 4.1 Перехід «Підручник ➔ Тренажер» (Шлюз компетенції)
Коли учень завершує вивчення теоретичного параграфа в `apps/study`:
1. Кнопка формує цільовий семантичний перехід:
   ```
   http://localhost:3002/practice/[courseSlug]/[skillSlug]?source=study&unit=[unitSlug]
   ```
2. Тренажер `apps/student`:
   - Миттєво активує вказаний курс (`params.courseSlug`);
   - Запитує з BKT-секвенсора задачі саме для вказаної навички (`params.skillSlug`);
   - Відображає плашку зворотного повернення: *«Повернутися до підручника [Урок] ↩»*.

### 4.2 Перехід «Тренажер ➔ Підручник» (Ліквідація когнітивної омани)
При виявленні систематичної помилки під час написання коду тренажер видає пряме посилання:
```
http://localhost:3006/courses/[courseSlug]/[moduleSlug]/[unitSlug]#misconception-[id]
```
Підручник автоматично відкриває відповідний параграф і позиціонує екран на блоці омани.
