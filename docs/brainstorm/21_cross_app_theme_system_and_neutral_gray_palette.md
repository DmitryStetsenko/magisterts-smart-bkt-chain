# 💡 Брейншторм та Архітектурна Концепція: Наскрізна Система Тем (Світла / Темна) та Кастомізація Палітри

## 📌 Вступ та Мета Документа
Цей документ фіксує концептуальний та технічний дизайн впровадження уніфікованої системи тем у мультипортальну екосистему **Smart-BKT-Chain** (`apps/study`, `apps/student`, `apps/teacher`, `apps/admin`, `apps/docs`).

Головні вимоги користувача:
1. **Підтримка Світлої (Light) та Темної (Dark) теми.**
2. **Перемикання теми в кожному застосунку:**
   - Через кнопку налаштувань / профіль користувача (`UserProfileDrawer` / `AppShellLayout` Settings Rail Tab).
   - Швидкий toggle прямо в UI без перезавантаження сторінки.
3. **Розділ налаштувань в Admin Portal (`apps/admin`):**
   - Керування глобальними пресетами та палітрою кольорів як для світлої, так і для темної теми.
   - Можливість попереднього перегляду та збереження наскрізних системних кольорів.
4. **Рефакторинг Темної Теми з переходом на нейтральні благородні сірі тони:**
   - Поточна темна тема має значний синій ухил (`slate-950` / `#090d16` / `#070a13` / сині підтони).
   - Новий вектор: **Нейтральний графітово-сірий та цинковий спектр (`neutral`/`zinc`)**, що зменшує навантаження на зір під час тривалого навчання, відповідає сучасним дизайн-системам (GitHub Dark Dimmed, Linear, Vercel) та усуває надмірну «синяву».
5. **Наскрізність (Cross-App Consistency):**
   - Синхронізація теми між додатками через `localStorage` (ключ `sbc-theme-mode`, `sbc-custom-theme-tokens`) та подію `storage` для миттєвого оновлення між вкладками.
   - Спільна дизайн-система токенів у `@sbc/ui`.

## 🎨 1. Колористична Філософія та Новий Баланс Палітри

### 1.1. Проблема поточної темної теми (Blue/Slate Tint)
Зараз у коді жорстко зашиті класи `slate-900`, `slate-950`, `bg-[#090d16]`, `border-slate-800/80`. Це:
- Створює холодний, синюватий відтінок, який контрастує зі стилем сучасних IDE (Monaco Editor VS Dark / Cursor) і втомлює очі.
- Ускладнює перемикання на світлу тему, оскільки стилі зашиті як статичні класи Tailwind `bg-slate-900`, а не семантичні CSS-змінні чи токени теми.

### 1.2. Нова Темна Тема (True Graphite / Zinc Dark)
- **Background Root:** `#121214` або `#161618` (глибокий нейтральний графіт замість синього `#090d16`).
- **Surface / Card:** `#1e1e21` або `#202024` (м'який графіт).
- **Subtle Surface / Elevated:** `#28282d`.
- **Borders & Dividers:** `#2e2e33` / `#333338` (чистий нейтральний контраст 1:1.5).
- **Text Primary:** `#f4f4f5` (чистий білий/цинковий).
- **Text Secondary / Muted:** `#a1a1aa`.
- **Text Tertiary:** `#71717a`.
- **Акценти залишаються семантичними:**
  - Study: Сапфірово-блакитний / `sky-500`
  - Student: Індиго-фіолетовий / `indigo-500`
  - Teacher: Аметистовий / `purple-500`
  - Admin: Смарагдовий / `emerald-500`

### 1.3. Світла Тема (Clean Paper & Graphite Light)
- **Background Root:** `#f9fafb` або `#f4f4f6` (м'який теплий папір, не 100% сліпучий білий).
- **Surface / Card:** `#ffffff` (чистий білий для карток та панелей).
- **Subtle Surface / Elevated:** `#f0f1f4`.
- **Borders & Dividers:** `#e4e4e7` / `#e5e7eb`.
- **Text Primary:** `#18181b` (глибокий контрастний вугільний).
- **Text Secondary / Muted:** `#52525b` / `#71717a`.
- **Акценти:** Ті самі кольорові ідентифікатори підсистем, адаптовані для світлого фону з високим коефіцієнтом доступності WCAG AAA.

## 🏛️ 2. Архітектура Наскрізних Токенів у `@sbc/ui`

Ми створюємо в пакеті `@sbc/ui` окремий модуль керування темами:
`packages/ui/src/theme/`:
- `theme.types.ts`: Типи теми (`ThemeMode = 'dark' | 'light' | 'system'`, `ThemeTokens`, `ColorRole`).
- `ThemeContext.tsx`: React Context + хук `useTheme()`, який:
  - Зчитує налаштування з `localStorage` (або `prefers-color-scheme`).
  - Додає або знімає клас `dark` на кореневому елементі `<html>` або `<body>`.
  - Динамічно інжектує/оновлює CSS-змінні токенів (`--sbc-bg`, `--sbc-surface`, `--sbc-border`, `--sbc-text`, тощо) у `:root` або `.dark`.
  - Слухає `window.addEventListener('storage')`, щоб зміна теми в Admin або Student миттєво підтягувалась у сусідній вкладці Study чи Teacher!
- `ThemeProvider.tsx`: Огортає лейаут або використовується всередині `AppShellLayout`.
- `ThemeToggle.tsx`: Компактна кнопка-перемикач Сонце/Місяць (`Sun`/`Moon`) для хедера або налаштувань.
- `defaultTokens.ts`: Базові пресети кольорів (Graphite Dark та Clean Light).

## 🎛️ 3. Місця Перемикання в UI Застосунків

1. **Header / Profile Drawer (`UserProfileDrawer`):**
   - У верхній частині `UserProfileDrawer` додається компактний перемикач теми (`Світла / Темна`).
   - Усі застосунки автоматично отримують перемикання через спільний компонент `UserProfileDrawer`.
2. **Settings Rail Tab (`AppShellLayout`):**
   - Нижня іконка шестерні (Settings) на вертикальній рейці Rail тепер може відкривати Drawer або модальне вікно швидких налаштувань (включаючи тему оформлення).
3. **Admin Portal (`apps/admin`):**
   - Новий підрозділ у табі `system` або окремий таб `🎨 Дизайн & Теми (Theme Studio)`:
     - Таблиця/контроли редагування базових токенів для Темної та Світлої тем:
       - Background Color (Root)
       - Surface / Card Color
       - Border Color
       - Primary Accent Color
       - Text Primary & Muted
     - Перемикач попереднього перегляду (Live Preview прямо в адмінці).
     - Кнопка **«Зберегти наскрізні налаштування»** (зберігає в `localStorage` та відправляє подію всім вікнам, з можливістю збереження на бекенд у конфігурацію системи).
     - Кнопка **«Скинути до рекомендованих сірих тонів»**.
