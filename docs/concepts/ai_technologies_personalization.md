# 🧠 Технології штучного інтелекту в системі «Smart-BKT-Chain» для персоналізації освітніх траєкторій

## 🎯 Відповідність затвердженій темі дослідження
> **Затверджена тема:** «Розробка навчальної онлайн-платформи з використанням штучного інтелекту для персоналізації освітніх траєкторій»  
> **Предметна галузь:** Інтелектуальні навчальні системи (Intelligent Tutoring Systems — ITS), моделювання знань учня (Student Modeling), адаптивні освітні траєкторії (Adaptive Learning Pathways).

Платформа **«Smart-BKT-Chain»** спроєктована як гібридна інтелектуальна навчальна система (ITS), в якій алгоритми штучного інтелекту функціонують на всіх ключових рівнях навчального процесу: від первинної діагностики ймовірнісного стану навичок до семантичного оцінювання відкритих відповідей та генерації індивідуального плану навчання.

## 🔬 1. Ймовірнісний ШІ: Телеметрично-модифікований Bayesian Knowledge Tracing (BKT)
* **Доменний модуль:** `apps/api/src/domain/bkt/` (`bkt-engine.ts`, `behavioral-adjuster.ts`).
* **Наукова сутність:** Прихована марковська модель (Hidden Markov Model — HMM), що моделює засвоєння кожної атомарної навички $k$ як бінарний латентний стан:
  $$\text{Стан} \in \{ \text{Засвоєно } (L), \text{ Не засвоєно } (\neg L) \}$$
* **Формула байєсівського оновлення знань:**
  $$P(L_t \mid \text{Obs}) = \frac{P(L_{t-1}) \cdot P(\text{Obs} \mid L)}{P(L_{t-1}) \cdot P(\text{Obs} \mid L) + (1 - P(L_{t-1})) \cdot P(\text{Obs} \mid \neg L)}$$
  $$P(L_t) = P(L_t \mid \text{Obs}) + (1 - P(L_t \mid \text{Obs})) \cdot P(T)$$
  де $P(T)$ — ймовірність переходу до стану знання в результаті спроби.
* **Інноваційна модифікація ШІ (Behavioral Adjuster):**
  У класичній моделі параметри випадкового вгадування $P(G)$ (Guess) та випадкової помилки/описки $P(S)$ (Slip) є фіксованими константами. У нашій системі вони **динамічно коригуються нейроповедінковим алгоритмом** на основі аналізу темпоральної телеметрії друку (WPM, довжини когнітивних пауз, коефіцієнта взаємодії з буфером обміну):
  - При фіксації надшвидкої вставки великого фрагмента коду з буфера: $P(G) \uparrow$ (ймовірність несамостійного розв'язку зростає).
  - При високому темпі самостійного введення з локальною синтаксичною опискою: $P(S) \uparrow$ (система не карає учня заниженням оцінки знань, кваліфікуючи це як механічну описку).

## 🧭 2. Інтелектуальне планування траєкторій (Dynamic Task Sequencing AI)
* **Доменний модуль:** `apps/api/src/domain/sequencing/task-sequencer.ts`.
* **Призначення:** Динамічний вибір оптимального наступного навчального об'єкта або практичної задачі на основі топології графа знань (Skill DAG) та поточного вектора $P(L_t)$.
* **Алгоритм адаптивної навігації:**
  1. **Критерій майстерності (Mastery Threshold):** Якщо $P(L_t) \ge 0.95$, навичка вважається засвоєною, відкриваючи доступ до наступних залежних вузлів онтологічного графа.
  2. **Режим ліквідації когнітивних прогалин (Remediation Mode):** Якщо після серії спроб $P(L_t) < 0.50$ або фіксуються аномальні паузи розгубленості, планувальник автоматично призупиняє просування вперед та формує коригувальну траєкторію:
     - пропонує задачу зниженої складності (Decomposed Scaffolding);
     - повертає студента до незасвоєного базового пререквізиту;
     - активує контекстну картку розбору помилки (Misconception Card).

## 📝 3. Каскадне семантичне оцінювання відкритих відповідей (Tier 1–3 NLP/LLM Judge)
* **Доменний модуль:** `apps/api/src/domain/evaluation/` (`open-answer-evaluator.service.ts`, `open-text-heuristic-evaluator.ts`).
* **Архітектура трьох рівнів (Cascaded Evaluation):**
  1. **Tier 1 (Детерміновані евристики та фільтрація аномалій):**
     - Детекція копіпасту формулювання завдання.
     - Алгоритм виявлення беззмістовного тексту/абракадабри (Gibberish Detector) на основі балансу голосних/приголосних та коефіцієнта різноманітності лексики (Type-Token Ratio — TTR).
     - Перевірка наявності обов'язкових фахових ключових понять та відсікання наповнення ключовими словами (Keyword Stuffing).
  2. **Tier 2 (Семантична векторна схожість):**
     - Порівняння відповіді з еталоном викладача через алгоритми косинусної схожості та N-gram зіставлення.
     - Автоматична ідентифікація типових когнітивних хиб (Misconceptions).
  3. **Tier 3 (Генеративний LLM Rubric Judge):**
     - Залучення великих мовних моделей (Gemini API) для багатоаспектного оцінювання за формалізованими педагогічними рубриками:
       - `correctness` (змістовна правильність тверджень);
       - `completeness` (глибина та повнота розкриття теми);
       - `keyConceptsCovered` (коректність застосування понятійного апарату).
     - Генерація пояснювального фідбеку зрозумілою для здобувача мовою.
  4. **Гібридний контур Human-in-the-Loop:** Відповіді, які потрапляють у «сіру зону» невизначеності ($0.45 \le \text{Score} \le 0.70$) або мають телеметричні ознаки несамостійності, автоматично маркуються статусом `PENDING_REVIEW` та делегуються викладачу для експертної верифікації.

## 💬 4. Інтелектуальний Сократівський тьюторинг (Socratic AI Tutor)
* **Функціонал:** Забезпечує персоналізований діалоговий супровід здобувача освіти в момент розв'язання задачі.
* **Принцип дії:** На відміну від звичайних генеративних чат-ботів, сократівський тьютор має системне обмеження: він **ніколи не видає готовий код або пряму відповідь**. ШІ аналізує поточний код учня, знаходить концептуальну помилку та формулює навідне питання, що стимулює критичне мислення та скеровує здобувача до самостійного знаходження вірного розв'язку.
