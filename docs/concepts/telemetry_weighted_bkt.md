# 🧠 Концепція Dynamic Telemetry-Weighted BKT & Multi-Disciplinary AI Platform

## 📌 Вступ та Проблематика
У класичній математичній моделі **Bayesian Knowledge Tracing (BKT)** оцінка знань $P(L_t)$ спирається виключно на бінарний результат виконання завдання (`isCorrect: true/false`). Це створює суттєву вразливість: **користувач може списати відповідь (копіпаст з AI / Web / готових джерел)** і отримати $P(L) \approx 99\%$, хоча реального засвоєння навички не відбулося.

В рамках проєкту **Smart-BKT-Chain** розробляється універсальна мультидисциплінарна освітня платформа. Вона поєднує **Language-Agnostic Telemetry**, **Dynamic BKT** та **самонавчальну нейромережу (Human-in-the-Loop AI)** для оцінювання знань з будь-яких предметів: **програмування, математика, іноземні мови, гуманітарні та природничі науки**.

## 🌐 1. Мультидисциплінарна Архітектура Завдань (Multi-Disciplinary Task Engine)

Система підтримує довільні навчальні курси завдяки уніфікованим адаптерам оцінювання (`TaskEvaluatorAdapter`):

```
                                      ┌──> CODE_RUNNER (JS, Python, C++, SQL, Java)
                                      │
[Завдання з БУДЬ-ЯКОГО предмета]     ├──> MATH_EVALUATOR (Символьні вирази, LaTeX, формули)
 (Математика, Англійська, Код тощо) ├──> LANGUAGE_EVALUATOR (Граматехніка, семантика есе, аудіювання)
                                      │
                                      └──> GENERAL_QUIZ / TEXT (Тести, відкриті тексти через LLM-Judge)
```

### 1.1. Оцінювання за предметами:
1. **Математика:** 
   - Автоматична перевірка символьних рівностей (SymPy/LaTeX parser).
   - Телеметрія фіксує покроковий ввід формули, паузи на роздуми та копіювання готового рішення з Photomath/WolframAlpha.
2. **Іноземні мови (Англійська тощо):**
   - Перевірка граматики, перекладів, творчих есе.
   - LLM-Judge (Gemini 2.5 Flash) оцінює семантичну точність і багатство словникового запасу.
   - Телеметрія виявляє використання Google Translate / DeepL через патерни масового вводу.
3. **Програмування & IT:**
   - Автоматичні юніт-тести в ізольованому середовищі + аналіз стилю.
4. **Теоретичні дисципліни (Історія, Право, Біологія):**
   - Семантичне оцінювання відповідей відкритими словами.

## 📐 2. Математична модель Dynamic Telemetry-Weighted BKT

### 2.1. Коефіцієнт Довіри Сесії ($\alpha$)
Вводиться універсальний динамічний коефіцієнт довіри сесії $\alpha \in [0, 1]$, який не залежить від предмета:

$$\alpha = (1 - \text{CopyPasteRatio}) \times \text{InteractionPacingNormalized} \times (1 - \text{AnomalyScore}_{\text{NN}})$$

Де:
- **$\text{CopyPasteRatio}$** — частка вставлених символів до загальної кількості символів у розв'язку.
- **$\text{InteractionPacingNormalized}$** — відповідність часових пауз та темпу вводу природному людському сприйняттю (наприклад, неможливо прочитати текст з математики і дати відповідь за 0.8 сек).
- **$\text{AnomalyScore}_{\text{NN}}$** — передбачення власної нейромережі щодо аномальності сесії.

### 2.2. Динамічний параметр вгадування / списування $P(G_{\text{dyn}})$
Параметр ймовірності вгадування динамічно масштабується:

$$P(G_{\text{dyn}}) = P(G_{\text{default}}) + (1 - \alpha) \times (0.95 - P(G_{\text{default}}))$$

- **При $\alpha = 1.0$ (повністю самостійна робота):** $P(G_{\text{dyn}}) = 0.2$. Приріст знань $P(L_t)$ максимальний.
- **При $\alpha = 0.0$ (100% копіпаст або аномалія):** $P(G_{\text{dyn}}) = 0.95$. Приріст знань $\Delta P(L) \approx 0$.

## 🤖 3. Власна Нейромережа & Continuous Active Learning Loop

Платформа реалізує **цикл постійного самонавчання нейромережі на реальних студентах (Human-in-the-Loop ML)**:

```
[1. Студенти розв'язують завдання (Будь-який предмет)]
                         │
                         ▼ (Біометрична телеметрія: ритм, паузи, копіпаст, вкладки)
[2. Збереження телеметричних векторів у БД]
                         │
                         ▼
[3. Кабінет Викладача (Teacher Portal)]
   (Викладач бачить аномалії та розмічає: "Чесно" / "Списано")
                         │
                         ▼ (Розмічений датасет)
[4. Автоматичне донавчання власної ML-моделі (PyTorch / TensorFlow)]
                         │
                         ▼
[5. Оновлена нейромережа краще розпізнає списування для нових потоків!]
```

### 3.1. Уніфікований Вектор Телеметрії для Нейромережі
Нейромережа отримує мовно-незалежний вектор взаємодії:
$$\mathbf{X} = [\text{TaskType}, \text{InterKeyIntervals}, \text{Time-to-First-Char}, \text{EditDistanceRatio}, \text{TabSwitchCount}, \text{PasteRatio}]$$

## 🗺️ 4. План реалізації у проєкті Smart-BKT-Chain

1. **Універсальний збір телеметрії (Language-Agnostic):** Фіксація біометрики вводу для будь-яких текстових та кодових полів.
2. **Агрегація & Розмітка у Кабінеті Викладача:** Інтерфейс підтвердження/спростування списування викладачем для формування навчального датасету.
3. **Навчання Власної ML-Моделі:** Модуль виявлення аномалій для передачі `AnomalyScore` у BKT Engine.
4. **Розширення типів оцінювачів:** Інтеграція підтримки коду, математики, мовних тестів та відкритих відповідей.
