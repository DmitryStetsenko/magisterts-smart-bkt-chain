# 🎓 Магістерська робота: Комп'ютерні науки (Smart-BKT-Chain)

## 📌 Паспорт дослідження
- **Галузь знань:** 12 Інформаційні технології
- **Спеціальність:** 122 Комп'ютерні науки
- **Назва проєкту:** **Smart-BKT-Chain** — Децентралізована інтелектуальна система адаптивного навчання та верифікації навичок програмування на основі моделі BKT і смарт-контрактів.

---

## 🎯 Наукова новизна та інженерна цінність
1. **Інтелектуальне моделювання знань:** застосування модифікованої моделі **Bayesian Knowledge Tracing (BKT)** з урахуванням поведінкової телеметрії редактора коду (час до першого символу, кількість запусків тестів, динаміка правок).
2. **Децентралізована верифікація результатів:** фіксація сформованих умінь та досягнутих станів майстерності (Knowledge Mastery) через смарт-контракти та Soulbound/Non-transferable токени (SBT).
3. **Мікросервісно-модульна монорепозиторна архітектура:**
   - `apps/api`: NestJS, Clean Architecture / Hexagonal Architecture, WebSockets, Prisma ORM, PostgreSQL.
   - `apps/student`: Next.js, Monaco Code Editor, інтерактивні квізи, візуалізація карти навичок.
   - `apps/teacher`: Моніторинг студентів у реальному часі, BKT-аналітика класу, черга перевірки.
   - `apps/admin`: Управління дисциплінами, модулями, завданнями та смарт-контрактами.
   - `apps/docs`: Інтерактивний портал документації системи.
