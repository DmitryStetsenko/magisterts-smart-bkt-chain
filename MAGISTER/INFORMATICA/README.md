## 💡 1. Концептуальне підведення проєкту Smart-BKT-Chain до теми

### Проблема традиційного навчання
У традиційній шкільній практиці (10–11 класи) розділ «Вебтехнології» здебільшого зводиться до пасивного вивчення статичної розмітки (HTML-теги, CSS-стилі). При цьому алгоритмічна лінія курсу інформатики вивчається відокремлено (на абстрактних прикладах у Python/Pascal/C++), що створює розрив між теоретичною алгоритмізацією та реальними прикладними IT-технологіями, які бачать учні в інтернеті.

### Концептуальний міст: Вебтехнології як прикладне алгоритмічне середовище
Сучасні вебтехнології (зокрема клієнтський JavaScript та маніпуляції з DOM-деревом) — це **потужний тренажер для формування алгоритмічної компетентності**:
1. **Лінійні алгоритми та структури вибору:** обробка подій інтерфейсу (`click`, `input`), валідація введених користувачем даних у форми через розгалуження (`if/else`).
2. **Циклічні алгоритми та ітератори:** обхід DOM-вузлів, динамічна генерація карток товарів, таблиць, галерей із масивів об'єктів (`for`, `forEach`, `map`).
3. **Алгоритми пошуку та фільтрації:** «живий пошук» по сторінці, фільтрація елементів інтерфейсу за категоріями, сортування списків.
4. **Асинхронні алгоритми:** запити до зовнішніх сервісів, таймери, анімації, обробка відповідей від сервера.

### Роль платформи Smart-BKT-Chain як засобу навчання
Платформа виступає **інтелектуальною комп'ютерно-орієнтованою системою навчання**, що забезпечує:
- **Інтерактивне робоче місце учня (`apps/student`):** повноцінний редактор коду (Monaco Editor) з миттєвим попереднім переглядом результатів та автоматизованою верифікацією виконання алгоритмів.
- **Адаптивність на основі моделі BKT (`apps/api`):** система в режимі реального часу відстежує стан сформованості кожної окремої алгоритмічної навички $P(L)$ та динамічно адаптує складність наступних веб-завдань, ліквідуючи прогалини учня.
- **Аналітичний дашборд учителя (`apps/teacher`):** прозорий тепловий зріз (Heatmap) знань класу, що дозволяє вчителю точково бачити, які алгоритмічні структури викликають найбільше труднощів.
- **Мотиваційний цифровий сертифікат (Web3/SBT):** фіксація досягнутого рівня алгоритмічної майстерності старшокласника.

## 🧩 2. Відповідність компонентів платформи завданням магістерської

| Елемент магістерського дослідження | Компонент у проєкті Smart-BKT-Chain | Роль та реалізація |
| :--- | :--- | :--- |
| **Діагностичний апарат** | Bayesian Knowledge Tracing (BKT Engine) | Оцінка ймовірності опанування алгоритмічної навички $P(L_t)$ учнем |
| **Середовище діяльності учня** | `apps/student` (Monaco Code Editor, Sandbox) | Написання алгоритмів на базі вебтехнологій (JS/DOM/HTML/CSS), запуск тестів |
| **Педагогічний моніторинг** | `apps/teacher` (Live Class Monitor, Matrix) | Візуалізація темпів засвоєння алгоритмічних навичок класом у реальному часі |
| **Телеметрія навчання** | Socket.IO / WebSockets Gateway, Event Tracker | Збір даних про процес мислення учня: паузи, час розв'язання, спроби тестів |
| **Підтвердження результатів** | Smart Certificates / Blockchain Proof | Фіксація підсумкового рівня алгоритмічної компетентності учня |

## 🛠️ 3. Що потрібно доробити / адаптувати в проєкті під цю магістерську

Щоб платформа стала повноцінною дослідно-експериментальною базою для шкільної магістерської роботи, доцільно реалізувати такі кроки:

### Крок 1. Створення профільного графа навичок (Knowledge Graph: "Веб-алгоритми")
Розробити та занести у базу даних (через Prisma Seed) деталізований перелік мікро-навичок (Knowledge Components — KC) для старшої школи:
- `KC_DOM_SELECT`: Пошук та маніпуляція вузлами DOM (алгоритмічний доступ до елементів).
- `KC_EVENT_LOGIC`: Розгалуження при обробці подій інтерфейсу (`addEventListener`, перевірка умов).
- `KC_ARRAY_RENDER`: Алгоритми обходу та відображення колекцій даних у веб-сторінці.
- `KC_FORM_VALIDATION`: Алгоритми перевірки коректності вхідних даних (регулярні вирази, логічні зв'язки).
- `KC_DYNAMIC_FILTER`: Алгоритми пошуку, фільтрації та сортування масивів об'єктів для інтерфейсу.
- `KC_ASYNC_TIMERS`: Алгоритми таймерів, лічильників та анімацій (`setInterval`, `setTimeout`).

### Крок 2. Банк шкільних адаптивних практичних завдань
Наповнити навчальний модуль серією завдань різного рівня складності (від репродуктивних до евристичних):
1. *Рівень 1:* «Створити інтерактивний лічильник відвідувачів або таймер зворотного відліку».
2. *Рівень 2:* «Реалізувати валідатор форми реєстрації (перевірка паролю, довжини, спеціальних символів)».
3. *Рівень 3:* «Розробити додаток "Список справ" (Todo List) з операціями додавання, видалення та зміни статусу».
4. *Рівень 4:* «Реалізувати живий пошук та фільтрацію каталогу товарів інтернет-магазину за ціною та назвою».

### Крок 3. Доопрацювання модуля попереднього перегляду та тестування в `apps/student`
- Забезпечити безпечну пісочницю (Iframe sandbox з підтримкою HTML/CSS/JS), де старшокласник бачить не лише код, а й візуальний інтерактивний інтерфейс свого веб-додатку.
- Реалізувати автоматичні юніт-перевірки (наприклад, симуляція кліку на кнопку та перевірка, чи змінився текст елемента згідно з алгоритмом).

### Крок 4. Доопрацювання аналітики для вчителя в `apps/teacher`
- Додати окремий звіт/вкладку: **«Зріз сформованості алгоритмічної компетентності»**:
  - Рівні: Початковий, Середній, Достатній, Високий.
  - Розподіл за критеріями: *знаннєвий* (розуміння конструкцій), *діяльнісний* (вміння реалізувати алгоритм), *рефлексивний* (ефективність дій у редакторі, швидкість пошуку помилок).

## 📑 4. Орієнтовна структура магістерської роботи на базі платформи

1. **Вступ:** актуальність формування алгоритмічного мислення в епоху цифровізації, суперечності між вимогами IT-галузі та застарілими методиками навчання вебтехнологій.
2. **Розділ 1. Теоретико-методичні засади формування алгоритмічної компетентності учнів старшої школи:**
   - Поняття та структура алгоритмічної компетентності старшокласників.
   - Аналіз змісту розділу «Вебтехнології» у чинних навчальних програмах з інформатики.
   - Психолого-педагогічні можливості інтелектуальних систем адаптивного навчання (ITS) на базі моделі BKT.
3. **Розділ 2. Модель комп'ютерно-орієнтованого середовища адаптивного навчання вебтехнологій:**
   - Побудова онтологічного графа алгоритмічних умінь у контексті вебтехнологій.
   - Математичні засади адаптації траєкторії навчання на основі Bayesian Knowledge Tracing.
   - Архітектура та функціонал платформи Smart-BKT-Chain як інструменту вчителя та учня.
4. **Розділ 3. Методика формування алгоритмічної компетентності та результати експериментального дослідження:**
   - Система практичних задач та методичні рекомендації для вчителів інформатики 10–11 класів.
   - Організація, етапи та методи проведення педагогічного експерименту (констатувальний, формувальний, контрольний етапи).
   - Статистичний аналіз результатів експерименту (перевірка статистичних гіпотез за критеріями Пірсона / Стьюдента / Манна-Вітні), що підтверджує ефективність розробленої методики.
