# 📚 Методичні рекомендації: Принцип формування та оформлення Списку використаних джерел (Спеціальність 014 «Середня освіта. Інформатика»)

Цей документ містить повний опис логіки побудови, принципів нумерації та стандартів оформлення бібліографічного списку кваліфікаційної магістерської роботи.

---

## 1. Загальний принцип формування (Порядок цитування у тексті)
Список використаних джерел побудовано за **принципом першої появи (наскрізного цитування) у тексті пояснювальної записки (Order of Appearance)** згідно з вимогами **ДСТУ 8302:2015** та **ДСТУ 3008:2015**:

- **Прив'язка номерів:** Перше джерело, на яке автор посилається у тексті (у Вступі або Розділі 1), отримує номер `[1]`. Кожне наступне унікальне джерело — наступний порядковий номер.
- **Повторне посилання:** При повторному цитуванні праці у наступних розділах новий номер не присвоюється — використовується її первинний номер (наприклад, `[1]` або `[1, c. 12]`).
- **Єдиний наскрізний перелік:** Джерела мовою оригіналу (латиницею та кирилицею) подаються в єдиному наскрізному списку без штучного поділу на мовні секції.

---

## 2. Тематично-змістовна логіка за розділами магістерської (Інформатика / Педагогіка)
Список джерел відображає міждисциплінарний характер дослідження — поєднання методики навчання інформатики, теорії педагогічних вимірювань та сучасних цифрових технологій:

| Діапазон | Тематичний блок | Характеристика джерел |
| :--- | :--- | :--- |
| **Початковий блок** | **Теорія навчання, психометрія та моделі адаптивності** | Психолого-педагогічні засади інтелектуальних систем навчання (ITS), когнітивні тьютори, базові моделі вимірювання знань здобувачів (BKT, IRT, теорія просторів знань Дойньона-Фальманя). |
| **Педагогічний блок** | **Методика навчання інформатики та програмування** | Дослідження специфіки засвоєння алгоритмізації учнями, навчальна аналітика відкритих завдань з кодингу, дидактичні виклики масового впровадження генеративного ШІ. |
| **Технологічний блок** | **Цифрові платформи, верифікація та децентралізовані сертифікати** | Застосування сучасних веб-технологій та блокчейн-реєстрів для фіксації освітніх досягнень, захисту цифрового портфоліо учня та академічної доброчесності. |
| **Праці українських науковців** | **Вітчизняний досвід змішаного навчання та цифровізації освіти** | Дослідження провідних українських науковців у галузі цифрової трансформації освіти, змішаного навчання та безпеки інформаційних систем у ЗВО та школах. |
| **Нормативний блок** | **Державні стандарти України** | ДСТУ 3008:2015 (Звіти у сфері науки і техніки), ДСТУ 8302:2015 (Бібліографічне посилання). |

## 4. Часті запитання (FAQ для захисту)

- **Чому обрано порядок появи, а не алфавітний?**  
  ДСТУ 8302:2015 та ДСТУ 3008:2015 офіційно передбачають обидва варіанти. Порядок появи посилань у тексті є найбільш наочним і зручним для читання дослідження, оскільки забезпечує прямий логічний зв'язок між тезою в розділі та відповідним першоджерелом.
- **Чи є стандарт новіший за ДСТУ 8302:2015?**  
  Ні, ДСТУ 8302:2015 є чинним базовим державним стандартом України.
