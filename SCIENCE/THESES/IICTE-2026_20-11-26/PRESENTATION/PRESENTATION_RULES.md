## 🏛️ 1. Базові правила з магістерської роботи та тез (`AGENTS.md` Rule 9 + `THESES_RULES.md`)

1. **Конструктивне та некатегоричне зіставлення з існуючими системами:**
   - Об'єктивно визнавати ефективність класичних підходів у їхніх доменних межах (LMS — для організації навчання й адміністрування, CTT/MCQ — для зрізового контролю, DKT — для великих платформ із десятками тисяч сесій, класичний BKT — як перевірена ймовірнісна база).
   - **Суворо заборонено:** принизливі, драматичні чи безапеляційні оцінки («вичерпали ресурс», «зайшли у глухий кут», «не працюють», «безпорадні», «застаріли», «критичні вади», «катастрофічний дефіцит», «чорна скринька» як ярлик-приниження, «унеможливлює», «неможливо»).
2. **Заборона категоричних заперечень щодо альтернативних методів (доповнення до Rule 9):**
   - **Суворо заборонено** писати безапеляційні заперечення на кшталт: *«не відображає»*, *«не розрізняє»*, *«не містить»*, *«не дозволяє»*, *«не враховує»* щодо інших підходів.
   - **Обов'язково** пом'якшувати через межі складності або фокус методу:
     - ❌ *«Простий підрахунок відсотка не відображає динаміку навчання»*
     - ✔️ *«За самим лише підрахунком відсотка правильних відповідей достатньо складно оцінити покрокову динаміку навчання»*
     - ❌ *«Класичний BKT не містить механізму дидактичного супроводу»*
     - ✔️ *«У базовому варіанті класичний BKT зосереджений переважно на оцінці бінарного результату й зазвичай доповнюється зовнішнім модулем дидактичного супроводу»*
3. **Заборона самозвеличення та ієрархічних претензій:**
   - **Заборонено:** «найкращий підхід», «єдино правильне рішення», «революційний», «проривний», «не має аналогів», «посідає провідне місце», «гарантує ідеальну точність».
4. **Етичність психолого-педагогічної термінології та нейтральність доброчесності:**
   - **Заборонено:** «студенти бездумно списують», «не хочуть мислити», «безпорадність», «абсолютний нуль», «пастка».
   - **Обов'язково:** «когнітивна втома», «нетипові патерни редагування», «індикатори підвищеного ризику», «потребує уваги викладача (Human-in-the-Loop)».
5. **Анти-кліше ШІ та заборона джерел РФ (Rule 12):**
   - **Заборонено:** «варто зазначити», «стрімкий розвиток», «відіграє ключову роль», «широкий спектр», «слід підкреслити», «не викликає сумніву», «формує цілісний механізм».
   - **0% джерел РФ.**
6. **Безособовий науковий стиль (0 «ми / наш / нами»):**
   - У зв'язку з одноосібним авторством займенники першої особи множини (`ми`, `наш*`, `нами`, `нам`, `нас`) **суворо заборонені** (уживаються нейтральні безособові форми: *«обрано»*, *«запропоновано»*, *«у системі реалізовано»*).

## 🎯 2. Спеціальні правила для доповіді та слайдів (`PRESENTATION/`)

1. **Епістемологічна обережність (припущення ≠ доведений факт):**
   - Усе, що не підтверджено польовим експериментом на реальних учнях, подається виключно через **ймовірність, ризик, очікування або модельний прогноз** (*«виникає висока ймовірність»*, *«існує ризик»*, *«ілюстративний прогноз»*, *«модельні показники вказують на потенційний виграш»*).
   - Заборонено подавати гіпотези чи типові спостереження як безапеляційні доведені факти.
2. **Пряма демаркація «Стандартний підхід → Авторські покращення → Приклади»:**
   - Спочатку чітко позначається **базовий стандартний підхід** (класичний BKT Корбетта–Андерсона, 1994).
   - Одразу після нього **прямо перелічуються конкретні авторські розширення**, які покращують цю систему (динамічне $P_{\text{adj}}(G)$ і $P(S)$, Skill DAG, омани + Сократівські підказки LLM, контур збору логів JSONL/CSV для EM-калібрування).
   - І лише після цього наводяться **конкретні приклади** (числові, ілюстративні та жива демонстрація).
3. **Наскрізна вісь — двошарова адаптивність:**
   - Уся презентація тримається на ідеї адаптивної освітньої траєкторії на двох рівнях: **мікро-адаптивність** (у реальному часі під кожного учня) та **макро-адаптивність** (уточнення параметрів кожної теми на накопиченій статистиці через EM-калібрування).
4. **Повна прозорість походження кожної цифри та перевірюваність у застосунку:**
   - Жодна цифра не може з'явитися «нізвідки» — для кожної прямо в тексті слайда має бути зрозуміло її походження:
     - **Літературні стартові пріори («холодний старт»):** `0,15 / 0,20 / 0,10 / 0,15` (Corbett & Anderson, 1994; Baker et al., 2008; Pelánek, 2017) + подальше EM-калібрування; `0,85` — теорія повного засвоєння Блума (`minMasteryThreshold = 0.85`).
     - **Конфігуровані експертні евристики (`BehavioralAdjuster`):** `< 3,5 с` → `0,85`; `> 120 WPM` / вставка → `0,90`; паузи `> 5000 мс`; `≥ 70%` автотестів → $P(S) = 0{,}25$.
     - **Математичне обмеження:** верхня межа `0,90` (`MAX_P = 0.90`) для чисельної стабільності знаменника формули Баєса.
     - **Методичні коефіцієнти банку завдань:** демпфування підказок Сократа `−15%` / `−30%`.
     - **Прямий арифметичний розрахунок (перевіряється в BKT-симуляторі):** `15% → 61%` (при $P(G)=0{,}15$) проти `15% → 32%` (при $P_{\text{adj}}(G)=0{,}90$).
     - **Результати комп'ютерної симуляції Монте-Карло (строго Таблиця 1 поданих тез `V-4.0`):** `500` агентів, `15` навичок → `−26,4%` (`19,3 → 14,2`), `−38,1%` (`18,6% → 11,5%`), `+35,5%` (`0,62 → 0,84`). Заборонено використовувати застарілі цифри (`28%`, `41%`, `91%`, `84.2%`).
5. **Живий текст без формалізму та мета-блоків (у `slides/*.md`):**
   - **Заборонено** вставляти у слайдовий сценарій шаблонні вітання/прощання (*«Доброго дня, мене звати...»*, *«Дякую за увагу»*), режисерські ремарки (*«Викладач каже:»*, *«Клікаємо мишкою»*) та технічні блоки (*«Ключові елементи на слайді (для NotebookLM)»*).
   - Кожен слайд містить лише **заголовок** і **чистий, природний, професійно-науковий текст по суті дослідження**.
6. **Версійність усіх релізів:**
   - Кожна зміна фіксується як новий версіонований файл (`V-X.Y-...`), оновлюється дзеркальна актуальна копія (`SLIDES_SCRIPT.md` / `План_виступу_Стеценко.docx`) та робиться запис у відповідному `RELEASE_LOG.md`.
