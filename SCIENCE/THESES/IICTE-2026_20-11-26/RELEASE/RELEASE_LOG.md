## 📝 Деталі Версій

### 🔹 Версія 1.2 (18 листопада 2026 року) — Академічна шліфовка, м'яка проблематизація та строга математична формалізація
- **Ключові вдосконалення:**
  1. **Принцип м'якої наукової проблематизації (Constructive Problem Framing):**
     - Повністю усунено різкі, категоричні та критичні оцінки: фрази на кшталт *«унеможливлює тонку діагностику»*, *«некритичне копіювання»*, *«чорні скриньки»*, *«тактичний відступ»* замінено на виважені, толерантні та конструктивні конструкції (*«певні обмеження для неперервного відстеження»*, *«труднощі з глибоким самостійним осмисленням»*, *«корекційне повернення за графом пререквізитів»* тощо).
  2. **Математична строгість моделі BKT:**
     - **Формула (3):** приведено до канонічної форми Corbett & Anderson (1994) без індексної неоднозначності: $P(L_n) = P(L_n \mid Y_n) + (1 - P(L_n \mid Y_n)) \cdot P(T)$.
     - **Формула (4):** виправлено відображення строгой нерівності критерію опанування компетенції $P(L_n) \ge \tau_{\text{mastery}}$ з експлікацією $\tau_{\text{mastery}} = 0{,}85$.
     - **Нова Формула (7):** введено строгий аналітичний зв'язок поведінкової телеметрії $C_{\text{trust}}$ з параметром вгадування $P(G)$:
       $$P_{\text{adj}}(G) = P(G) + (1 - P(G)) \cdot (1 - C_{\text{trust}})$$
       із доведенням його граничних властивостей (при $C_{\text{trust}} \to 0 \implies P_{\text{adj}}(G) \to 1{,}0$, що блокує несамостійний приріст знань).
     - **Формула (6):** додано обмеження опуклої лінійної комбінації $w_i \ge 0, \ w_1 + w_2 + w_3 = 1$ та розкрито сутність $\Delta t_{\text{pause}}$ як нормалізованої медіани когнітивних пауз.
  3. **Справжнє експериментальне обґрунтування (Monte Carlo Simulation):**
     - Додано точні параметри експерименту в Розділі 4: $M = 500$ синтетичних навчальних агентів, Skill DAG з $m = 15$ концептів, базові параметри $P(L_0) = 0{,}15, P(T) = 0{,}20, P(G) = 0{,}15, P(S) = 0{,}10$.
  4. **Типографічна чистота та усунення артефактів:**
     - Замінено знак номера на коректну латинську літеру $N$ ($n = 1, 2, \dots, N$);
     - Виправлено індексацію $P(L_{n-1})$ та грецькі літери $\psi(\text{WPM})$, $\varphi(\Delta t_{\text{pause}})$, $\tau_{\text{mastery}}$;
     - Усунено кириличні двійники в термінах `HMM`, `Bayesian`, `KC_j`;
     - Експлікацію до формули (5) розміщено строго після формули згідно з ДСТУ;
     - У таблиці забезпечено нерозривний запис відсотків (`26,4%`).
  5. **Результати аудиту якості (`src/audit_theses.py`):**
     - Обсяг: **1 303 слова, 3.62 сторінки** (ідеально в межах нормативу 2–4 сторінки);
     - 7 нативних формул Word Equation (`m:oMath`);
     - 0 заборонених слів / кліше;
     - 0% джерел РФ.
